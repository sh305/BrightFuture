# Bright Future Computer Institute - React + MUI

## Requirements
- Node.js 18+ (Node.js 20+ recommended)

## Run
npm install
npm run dev

Open the URL shown by Vite (usually http://localhost:5173).

## Important
This is a frontend-only project. It has NO database, NO ASP.NET backend and NO authentication server.
Admission and contact forms show a success message only; submitted data is not stored.

## Build
npm run build
npm run preview
